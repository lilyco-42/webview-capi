📖 入门手册

快速开始 (5 分钟)

  1. 点击「新建项目向导」
  2. 选择「小白模式」
  3. 选择编程语言 (推荐 Python 或 C)
  4. 输入项目名称和 URL
  5. 选择目标平台
  6. 点击「生成项目」
  7. 运行 cd my-app && lyco run
